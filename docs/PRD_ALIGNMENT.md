## Verification

Automated checks cover concurrent free imports, duplicate rejection, asset rollback, deletion freeing capacity, Pro capacity, grandfathered project edits, app entry-point paywalls, free intermediate movement/undo, catalog rejection of subscriptions, restoration/identity behavior, provenance and sanitized sheet metadata. The existing browser verifier also checks the free capacity boundary before using the explicitly labeled development purchase simulation.

Validation run: 709 tests passed across 61 files; workspace type checks, lint and production build passed. The real Chrome editor verifier passed import/rendering, free capacity rejection, development Pro duplication, shared-asset deletion, offline full-browser restart and bundled starter capture. Xcode project syntax validation passed. Static iPhone release preflight reports seven missing configuration inputs. Browser rendering and fake-store tests do not prove native billing, hardware performance or iOS share delivery.
